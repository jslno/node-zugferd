## Installation

<Steps>
    <Step>
        ### Install the plugin
        
        Make sure the Java JRE is installed on your system, as the Mustang validator relies on it to run. You can download it from the [official Java website](https://www.java.com/en/download/).
        
        ```package-install
        @node-zugferd/validator-mustang
        ```
    </Step>
    <Step>
        ### Add the plugin to your instance
        
        ```ts title="invoicer.ts"
        import { zugferd } from "node-zugferd";
        import { en16931 } from "@node-zugferd/en-16931";
        import { mustang } from "@node-zugferd/validator-mustang"; // [!code highlight]
        
        export const invoicer = zugferd({
          profiles: [en16931],
          plugins: [
            mustang(), // [!code highlight]
          ],
          // ...
        });
        ```
    </Step>
</Steps>

## Usage

### Manual validation

```ts
import { readFile } from "node:fs/promises";
import { invoicer } from "@/lib/invoicer";

try {
  await invoicer.mustang.validate("en-16931", await readFile("factur-x.xml", "utf-8")); // [!code highlight]
  await invoicer.mustang.validate("en-16931", await readFile("invoice.pdf")); // [!code highlight]
} catch (error) {
  if (error instanceof ZugferdValidationError) {
    console.log(error.issues);
  } else {
    throw error;
  }
}
```
