# Default Template

A ready-made PDF invoice template that works with the Templates Plugin, with built-in translations and page size options.

### Prerequisites

Requires the [Templates Plugin](https://node-zugferd.jsolano.de/docs/plugins/templates) to be set-up.

### Installation

```bash
npm install @node-zugferd/default-template
```

### Documentation

For more information, please refer to the [Templates Plugin documentation](https://node-zugferd.jsolano.de/docs/plugins/templates).
