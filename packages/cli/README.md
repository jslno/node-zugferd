# node-zugferd CLI

node-zugferd comes with a built-in CLI to help you set up a project, parse invoices to JSON, and upgrade node-zugferd packages.

### **Init**

The CLI includes an `init` command that can be used to initialize a new project, or add additional configuration to an existing project.

```bash
npx @node-zugferd/cli@latest init
```

### **Parse**

Parses a ZUGFeRD invoice and prints the result as JSON.

```bash
npx @node-zugferd/cli@latest parse
```

### **Upgrade**

Upgrades the node-zugferd packages in a project to their latest versions.

```bash
npx @node-zugferd/cli@latest upgrade
```
