# Parser Plugin

> [!WARNING]
> Parsing is currently experimental, and the API is subject to change. XRechnung and Order-X profiles are not supported yet.

Read Factur-X and ZUGFeRD invoices from XML or PDF/A-3.

### Installation

```bash
npm install @node-zugferd/parser
```

### Documentation

For more information, please refer to the [Parser Plugin documentation](https://node-zugferd.jsolano.de/docs/plugins/parser).
