# Basic Profile

This profile includes [BASIC WL](https://node-zugferd.jsolano.de/docs/profiles/basic-wl) with some details at line level. It is a subset of EN 16931, which contains all mandatory fields including those on which business rules from the EN 16931 may apply. It is a compliant CIUS (Core Invoice Usage Specification), which means that all business rules of the EN 16931 apply.

### Installation

```bash
npm install @node-zugferd/basic
```

### Documentation

For more information, please refer to the [Basic Profile documentation](https://node-zugferd.jsolano.de/docs/profiles/basic).
