# Order-X Comfort Profile

The COMFORT Profile is the [BASIC](https://node-zugferd.jsolano.de/docs/profiles/order-x-basic) profile with more information available optionally, allowing multiple delivery, Buyer Requisitioner Party, Invoicee Party, VAT information except VAT breakdown, Allowances and Charges on line and document levels and more details:

- <u>**on Line level**</u>: item Characteristics, additional referenced product documents, line reference ID of Quotation and Catalog Reference Documents, Additional Referenced Documents, Gross Price and price discount, Allowances and Charges, Delivery or Pick-up Date or period for each item (allowing multiple delivery on the same location), VAT codes on line.

- <u>**on Document level**</u>: with Buyer Requisitioner Party, Invoicee Party, Sales Order Reference (issued by the Seller), Tender or Lot Reference, Catalog Reference Document, Additional Referenced Documents, Ordered Object Identifier, Project Reference, Delivery Terms Location, Ship To and Ship From legal and VAT IDs, Payment means, Charges and Allowances on Document level with VAT codes.

### Installation

```bash
npm install @node-zugferd/order-x
```

### Documentation

For more information, please refer to the [Order-X Comfort Profile documentation](https://node-zugferd.jsolano.de/docs/profiles/order-x).
