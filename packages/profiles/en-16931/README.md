# EN 16931 Profile

This profile includes [BASIC](https://node-zugferd.jsolano.de/docs/profiles/basic), with all the additional data required by the European Semantics Standard, whether optional or conditional. It is fully compliant to EN 16931, focussing on the core elements of an electronic invoice.

### Installation

```bash
npm install @node-zugferd/en-16931
```

### Documentation

For more information, please refer to the [EN 16913 Profile documentation](https://node-zugferd.jsolano.de/docs/profiles/en-16931).
