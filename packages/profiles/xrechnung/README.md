# XRechnung Profile

This profile has been included specifically to include invoices for Germany. The validity of the structure is based on and is under the sole responsibility of KoSIT, Germany's central coordination agency for IT's e-invoice CIUS "XRechnung". It is defined as the standard for electronic invoices issued to public administrations and may include specific business rules to EN 16931 in order to comply with national laws and regulations.

### Installation

```bash
npm install @node-zugferd/xrechnung
```

### Documentation

For more information, please refer to the [XRechnung Profile documentation](https://node-zugferd.jsolano.de/docs/profiles/xrechnung).
