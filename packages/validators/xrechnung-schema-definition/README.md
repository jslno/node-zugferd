# XRechnung Schema Definition

Bundle of XRechnung schema definitions for the XSD Validator Plugin.

### Prerequisites

Requires [XSD Validator Plugin](https://node-zugferd.jsolano.de/docs/plugins/validators/xsd) to be setup first.

### Installation

```bash
npm install @node-zugferd/xrechnung-schema-definition
```

### Documentation

For more information, please refer to the [XSD Validator Plugin documentation](https://node-zugferd.jsolano.de/docs/plugins/validators/xsd#xrechnung).
