# Mustang Validator Plugin

Validate invoice XML with the Mustang CLI.

### Prerequisites

Requires a Java runtime, with `java` on your `PATH`. When `JAVA_HOME` is set, setup looks in `JAVA_HOME/bin`.
You can download a runtime from the [official Java website](https://www.java.com/en/download/).

### Installation

```bash
npm install @node-zugferd/validator-mustang
```

### Documentation

For more information, please refer to the [Mustang Validator Plugin documentation](https://node-zugferd.jsolano.de/docs/plugins/validators/mustang).
