# KoSIT Validator Plugin

Validate EN 16931 and XRechnung invoice XML against the official KoSIT rules (XML Schema, EN 16931 Schematron, XRechnung Schematron) in-process, without Java.

### Installation

```bash
npm install @node-zugferd/validator-kosit
```

### Documentation

For more information, please refer to the [KoSIT Validator Plugin documentation](https://node-zugferd.jsolano.de/docs/plugins/validators/kosit).
